# Oil & Gas Global Simulator

Цифровой двойник мировой нефтегазовой логистики.

Архитектура разделена на три контура:

1. Core Simulation & Logistics Engine
   - SimPy-события
   - добыча, хранение, порты, трубопроводы
   - агенты танкеров

2. Chaos, Market & Geopolitics Engine
   - цены
   - фрахт
   - санкции
   - штормы, лед, аварии, блокировки проливов

3. 3D Earth & Telemetry Frontend
   - FastAPI + WebSockets
   - Three.js / Globe.gl
   - панель управления кризисами

## Этап 1

Реализованы:

- геопространственный граф мира;
- морской мультиграф;
- трубопроводный граф;
- ограничения по осадке судов;
- Суэцкий канал, Босфор, Датские проливы, Малакка, СМП;
- STS-зоны;
- проверка маршрутов для VLCC / Suezmax / Aframax / LNG-газовозов;
- диагностический стенд verify_stage1.py.

## Быстрый старт

1. Создать виртуальное окружение:

    python -m venv .venv

2. Активировать окружение:

    .venv\Scripts\activate

3. Установить зависимости:

    pip install -r requirements.txt

4. Запустить проверку Этапа 1:

    python verify_stage1.py

## Структура

- core/ — модели, конфигурация, мировой граф, будущий SimPy engine
- engines/ — будущие модули routing, market, chaos
- data/ — будущая экспортируемая топология мира
- frontend_3d/ — заготовка 3D-фронта
